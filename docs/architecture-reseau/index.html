Suite

Actions recommandées

  • Réparer ou recâbler les 8 prises défectueuses, en priorité la direction (RJ45 + RJ11) et le téléphone IP.
  • Relever les prises du 2ème étage (switch sur le port 23 du core).
  • Remplacer le switch D-Link non administré du service incubation par une prise directe vers le switch d’étage.
  • Séparer les sous-réseaux : administration, caméras PoE, postes, téléphonie IP, chacun dans son VLAN.
  • Raccorder le switch Innovation et noter son port côté switch principal.
